# controle-financas — client

Front em React 19 + Vite 8 + Tailwind 4. Veja o README da raiz do projeto.

```sh
npm install
npm run dev       # http://localhost:5173 (API em VITE_API_URL ou http://localhost:3000/api)
npm test          # Vitest
npm run lint      # oxlint
npm run build     # gera ../docs para o GitHub Pages
```
